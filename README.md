An open-world crime game in the browser: a neon coastal city to walk and drive through, traffic and pedestrians, cars to take, a wanted level with police response, jobs and a story, a minimap HUD, and a save. Everything is original, drawn and scored by the game's own code, and it plays offline.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
